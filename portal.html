《動元力國際微股東加入合約書》

甲方：動元力國際股份有限公司
代表人：黃光啟執行長

乙方：微股東加入人（投資人）

甲乙雙方本於誠信原則，就乙方參與甲方「微股東募集專案」之權利義務，達成合意，訂立本合約如下：
________________________________________

第一條｜合約目的
本合約係乙方參與甲方所推出之「動元力微股東募集（五年期）」方案，
乙方依本合約繳付參與金額，甲方依約提供產品領取、分紅分享及其他權益。
________________________________________

第二條｜方案內容與參與金額
1. 乙方加入「微股東專案」一股（五年期），同時取得「品牌經銷商」之資格
2. 乙方加入金額（參與金）：新台幣壹拾萬元整（NT$100,000）
3. 合約期間：共 60個月（五年）。
________________________________________

第三條｜付款方式
乙方同意於簽約後3日內繳付參與金，並提供繳費證明。
乙方完成付款後，甲方應提供收款證明或收據。
________________________________________

第四條｜產品領取權益
1. 自合約生效之次月起，乙方每年可領取 「動元活力蔬果餐包」12盒。
2. 連續領取期間為五年。
3. 領取方式：宅配（運費由甲方負擔，地址同以上通訊地址）
4. 若因乙方因素導致宅配配送不成功需重新配送，乙方應自行負擔補寄的運費。
________________________________________

第五條｜分紅權益
1. 合約有效期間內，乙方享有「全國分紅」權益。
2. 乙方可與所有微股東共同分享甲方 全國營業額之2%分紅。
3. 分紅發放方式：每月結算一次，由甲方於隔月20日前發放。
4. 分紅計算、資格認定與分配方式，依甲方制度與公告規則執行。
5. 分紅金額會依公司營運狀況、分紅規則及微股東人數變動而調整。
________________________________________

第六條｜海外豪華旅遊權益
1. 合約有效期間內，乙方享有 「海外豪華旅遊乙次」 之資格。
2. 旅遊舉辦時間、地點與行程由甲方公告安排。
3. 旅遊包含／不包含項目：
• 含機票、住宿、餐食
• 不含個人消費、簽證、保險等（甲方應於活動前公告細節）
4. 若因個人因素無法參加，視同放棄。
________________________________________

第七條｜介紹獎金
1. 乙方每成功介紹一位新微股東加入（完成簽約與付款），乙方可領取 介紹獎金NT$5,000。
2. 發放時間：新微股東完成付款後隔月20日發放。
3. 若發生退約／退款情形，甲方得扣回或要求返還已發放之介紹獎金。
________________________________________

第八條｜旅遊團領導人分紅加碼資格
1. 乙方於 2026/12/31 前 成功邀約達成 30人旅遊團 並成為領導人者，可獲得「分紅資格加碼」。
2. 加碼內容：乙方每月可再額外獲得一份公司全國分紅共享資格（依甲方制度公告執行）。
3. 達成條件之認定、團員資格、計算方式，依甲方制度與公告為準。
4. 本加碼資格僅限合約有效期間內。
________________________________________

第九條｜五年期滿公司附買回（10萬元）
1. 合約期滿（60個月）後，甲方同意辦理「附買回」。
2. 買回金額：新台幣壹拾萬元整（NT$100,000）。
3. 買回方式：
• 乙方於期滿後一個月內提出申請。
• 甲方於收到申請後10個工作日內完成買回款項支付。
4. 若乙方未於期限內提出申請，視同放棄權益。
________________________________________

第十條｜期滿後資格取消
合約五年期滿後，乙方之「微股東福利」即行取消，包括但不限於：
• 領取餐包60盒
• 共享全國分紅2%之資格
• 海外豪華旅遊乙次
• 介紹獎金制度
________________________________________

第十一條｜提前終止／退約處理
1. 若乙方欲於合約期間內提前終止，須提前10日書面通知甲方。
2. 提前終止之處理方式：依剩餘月份比例部分退還。
3. 若乙方有以下情形，甲方得終止合約並停止權益：
• 提供不實資料
• 破壞公司名譽／惡意造謠
• 違反公司制度或法律規定
________________________________________

第十二條｜風險揭露與特別聲明
1. 乙方了解本合約為「微股東專案」權益方案，分紅共享與相關權益以甲方制度與營運狀況為準，不得異議。
2. 乙方了解：本公司營業額、分紅金額不保證固定，可能因市場、營運、人數與制度調整而變動。
3. 本合約所稱「微股東」係方案稱呼與權益代稱，並不當然等同公司法上股票股權之登記股東資格。
________________________________________

第十三條｜個資與保密
乙方同意甲方為履行本合約及相關通知而蒐集、處理及利用乙方個人資料，甲方應善盡保密義務。
________________________________________

第十四條｜爭議處理
本合約如有未盡事宜，依中華民國法律處理。
若發生爭議，雙方同意以 甲方所在地之地方法院 為第一審管轄法院。
________________________________________

第十五條｜合約份數
本合約為電子合約，由乙方填寫完個人資料、勾選同意並於電子簽名板上親筆簽名送出後生效。
